# TyrQuake-Miyoo

This branch is the [TyrQuake libretro core](https://github.com/libretro/tyrquake) (Quake) tuned for
the Miyoo Mini Plus with OnionOS: faster at the native 640x480 (the renderer uses both CPU
cores), save states for Onion's Game Switcher, and savegames that load.

Installing, the Game Switcher, settings and building: **[miyoo/README.md](miyoo/README.md)**.
Measurements and technical notes: [miyoo/NOTES.md](miyoo/NOTES.md).
